# 原版说明：海南旅游文化宣传 H5

根据毕业设计《海南旅游文化宣传H5交互设计与制作》的页面体系制作的可运行移动端站点。采用 HTML5 + CSS3 + 原生 JavaScript + Canvas，无框架依赖，无后端/账号/数据库要求。

## 立即体验

1. 双击 `index.html` 可直接打开（部分浏览器的分享/下载行为受本地文件权限限制）。
2. 推荐在工程目录执行 `python -m http.server 8080`，再打开 `http://localhost:8080`。
3. 将整个文件夹内容上传至任意支持静态站点的 HTTPS 托管服务即可公开访问。

## 已实现功能

- 启动加载动画，海南主题首页，开始探索。
- 以海南岛轮廓为中心的五类文化热点，点击卡片、进入详情、返回地图。
- 自然景观/人文古迹/黎苗文化/非遗技艺/海南美食的横向切换卡片。
- 地点访问记录与文化印章收集分开管理；页面刷新后本机保存进度。
- 黎锦纹样三种图案互动；清补凉四种食材拖动/点击组合。
- 5 道海南文化单选题、即时正误反馈和知识解释；已回答题目不可重复计分。
- 印章数量解锁答题；结果页个性称号、文化关键词与推荐线路。
- Canvas 绘制导出专属 PNG 海报，原生分享或复制页面链接；重新体验。
- 音效开关、移动端竖屏适配、安全区域、动画低性能降级。

## 可配置项（请按最终答辩需求确认）

编辑 `data.js`：

- `config.quizUnlockStamps`：答题解锁需要的文化印章数，目前为 3。论文只写「达到设定条件」，未规定具体枚数。
- `config.shareUrl`：替换为你实际部署的 HTTPS 地址，目前是占位 `https://example.com/hainan-h5`。
- `categories`：全部探索分类、景点、文字与推荐线路；可继续添加内容。
- `questions`：五道题的题干、选项、答案及解析；论文没有给出完整原始题库。
- `patterns`：纹样说明；这里以几何结构的设计说明替代对具体黎锦纹样宗教/族群寓意的无根据断言。

## 交付边界

源码和静态页面已完成；不代表已部署到公网，也不代表已经经过所有手机/微信设备的真实兼容性测试。由于没有论文作品的原始 Figma/PSD/AE 图片或可运行旧H5，本项目采用原创 SVG/CSS 绘制同风格插画，而不是宣称逐像素还原。

海报的 Canvas 图片可保存；**二维码尚未生成真实二维码**，因为公开的正式 H5 地址未提供。为避免绘制不可扫描的伪二维码，当前海报底部使用正式部署后替换链接的提示。真实可扫二维码建议在取得正式域名后再生成和加入。

背景音乐：项目内提供可开关的轻触提示音，不自带有版权争议的背景乐曲文件。若要持续背景音乐，可后续加入获授权的本地 MP3 资源并接入音频播放模块。
